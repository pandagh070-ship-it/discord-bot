# Eto Discord Bot ❄️

بوت Eto Network باستخدام Node.js و discord.js 14.

## الأوامر الجديدة
- `/afk دخول`: يدخل البوت إلى الروم الصوتي المحدد ويبقى فيه، ويتم حفظ الروم لاستعادة الاتصال بعد إعادة تشغيل البوت.
- `/afk خروج`: يخرج البوت من الروم ويحذف وضع AFK المحفوظ.
- `/afk حالة`: يعرض الروم الذي يوجد فيه البوت.
- `/مساعدة`: يعرض فئات الأوامر.
- `/عضو` و`/سيرفر`: معلومات العضو والسيرفر.
- `/مسح`: حذف 1 إلى 100 رسالة حديثة.
- `/قفل` و`/فتح`: منع أو السماح بالكتابة في الروم الحالي.
- `/بطء`: ضبط مهلة الرسائل.
- `/مهلة`: تقييد عضو مؤقتاً.
- `/طرد` و`/حظر`: إجراءات الإشراف على الأعضاء.

## الأوامر السابقة
- `/تفاعل تشغيل` و`/تفاعل ايقاف`: تذكير كل ساعتين، والإعداد محفوظ.
- `/تحذير`: تسجيل تحذير في روم السجل ومحاولة إرساله للعضو في الخاص.
- `/موسيقى تشغيل` و`/موسيقى ايقاف`: تشغيل الروابط التي تدعمها مكتبة play-dl. قد ترفض بعض روابط YouTube التشغيل بسبب قيود المصدر.
- `/عدد_نشطين`: عداد للأعضاء المتصلين، دون البوتات، مع تحديث تلقائي.
- `/تحديث`: إعلان تحديث مع منشن الجميع.
- `/رساله`: إرسال رسالة خاصة إلى عضو.

## صلاحيات وإعداد
1. ثبّت Node.js 20.11 أو أحدث.
2. نفّذ `npm install`.
3. أضف `DISCORD_TOKEN` و`CLIENT_ID` إلى متغيرات البيئة، ويمكن إضافة `GUILD_ID` للتسجيل السريع داخل سيرفر الاختبار.
4. فعّل Server Members Intent وPresence Intent من Discord Developer Portal إذا أردت عداد المتصلين.
5. امنح البوت صلاحيات View Channels وSend Messages وEmbed Links وConnect وSpeak وManage Messages وManage Channels وModerate Members وKick Members وBan Members حسب الأوامر التي ستستخدمها.
6. نفّذ `npm run register` لتسجيل الأوامر، ثم شغّل البوت.

أوامر الإدارة تظهر فقط لمن يملك الصلاحية المطلوبة. لا تشارك توكن البوت مع أحد.
