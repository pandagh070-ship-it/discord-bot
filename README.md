# Eto Discord Bot

بوت موسيقى بسيط باستخدام Node.js و discord.js 14.

## الأمر الحالي
- `/music play`: اختيار أغنية من مجلد `songs/` وتشغيلها في الروم الصوتي الذي يوجد فيه المستخدم.
- `/music stop`: إيقاف التشغيل ومغادرة الروم الصوتي.

## إضافة الأغاني
1. ضع ملفات الصوت داخل مجلد `songs/`.
2. الصيغ المدعومة: MP3 و WAV و OGG و FLAC و M4A.
3. أعد تشغيل عملية التسجيل `npm run register` حتى تظهر أسماء الأغاني الجديدة في قائمة الأمر.
4. تظهر حتى 25 أغنية في قائمة Discord؛ ضع أسماء ملفات واضحة وبسيطة.

## الإعداد
أضف `DISCORD_TOKEN` و `CLIENT_ID` إلى متغيرات البيئة. يمكن إضافة `GUILD_ID` لتسجيل الأمر فوراً في سيرفر واحد. امنح البوت صلاحيات View Channel وConnect وSpeak.
