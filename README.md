# Eto Discord Bot

بوت ديسكورد يدعم تشغيل الأغاني من الملفات المحلية وروابط YouTube وSpotify.

## الأوامر
- `/music play song`: تشغيل أغنية محفوظة في مجلد `songs/`.
- `/music play url`: تشغيل رابط أغنية من YouTube أو Spotify.
- `/music stop`: إيقاف التشغيل ومغادرة الروم الصوتي.

## روابط YouTube وSpotify
ضع رابط أغنية YouTube في خيار `url` وسيستخرج البوت مسار الصوت باستخدام yt-dlp.
عند وضع رابط Spotify لأغنية، يقرأ البوت اسم الأغنية والفنان من Spotify ثم يبحث عن نتيجة مطابقة على YouTube لتشغيلها. Spotify لا يوفّر للبوت بث الصوت مباشرة، لذلك قد تختلف النسخة التي يعثر عليها البحث.

## الملفات المحلية
ضع ملفات MP3 أو WAV أو OGG أو FLAC أو M4A داخل مجلد `songs/`، ثم شغّل `npm run register` لتحديث قائمة الأغاني. تظهر حتى 25 أغنية في قائمة Discord.

## الإعداد
أضف `DISCORD_TOKEN` و`CLIENT_ID` إلى متغيرات البيئة. يمكن إضافة `GUILD_ID` لتسجيل الأمر فوراً في سيرفر واحد. امنح البوت صلاحيات View Channel وConnect وSpeak.
