# Songs

ضع ملفات الصوت هنا بصيغة `.m4a` أو `.mp3` أو `.wav` أو `.ogg` أو `.webm`.

بعد إضافة أغنية، استخدم `/music_list` ثم `/play_music` لاختيارها.

أوامر الموسيقى:
- `/play_music` اختيار أغنية
- `/music_list` عرض الأغاني
- `/queue` قائمة الانتظار
- `/music_next` التالية
- `/music_repeat` تكرار
- `/music_stop` إيقاف
