# صوت مؤثر توسيع مجال 🤞

ارفع ملف الصوت الخاص بمؤثر **توسيع مجال** داخل هذا المجلد نفسه.

الملفات المدعومة: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.webm`.

يفضّل رفع ملف صوت واحد فقط، لأن الأمر `/مؤثره` سيشغّل أول ملف صوت يجده في هذا المجلد، ثم بعد 5 ثوانٍ سيحاول البوت كتم الأعضاء البشر وفصلهم من المكالمة الصوتية. لا يطردهم من السيرفر.
